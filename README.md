# 🎮 Tic-Tac-Toe Game

A simple and fun **Tic-Tac-Toe** game built using **HTML, CSS, and JavaScript**. Play against a friend and enjoy a smooth, responsive design!

---

## 🛠️ Features

- 🔄 Two-player mode
- ✅ Win detection (rows, columns, diagonals)
- 🎨 Stylish, responsive UI
- 🧼 Game reset functionality
- 📱 Mobile-friendly design

---

## 🔧 Tech Stack

- 🖼️ HTML
- 🎨 CSS
- ⚙️ JavaScript (vanilla)

---

## 📜 How to Run Locally

1. Clone the repo:
   ```bash
   git clone https://github.com/YOUR_USERNAME/tic-tac-toe.git
   ```
2. Open `index.html` in your browser
3. Enjoy the game!
